# Playbook OSINT & CTI - X-Finder Intelligence Hub

## 1. Méthodologie OSINT (Open Source Intelligence)
- Étape 1 : Collecte passive d'empreintes numériques (DNS, WHOIS, profils sociaux LinkedIn, GitHub, YouTube).
- Étape 2 : Corrélation des identifiants et cartographie des relations.
- Étape 3 : Analyse des métadonnées (EXIF, répertoires ouverts, versions de logiciels).
- Étape 4 : Synthèse exploitable et diffusion sécurisée.

## 2. Cyber Threat Intelligence (CTI)
- Frameworks clés : MITRE ATT&CK, Cyber Kill Chain, Diamond Model.
- Indicateurs de compromission (IOC) : Hash SHA256, adresses IP malveillantes, domaines de C2.
- CVE Priority Scoring : CVSS v3.1, exploitation active 'in the wild' (CISA KEV catalog).

## 3. Chasse aux Opportunités Cybersécurité
- Plateformes de CTF : CTFtime, Hack The Box, TryHackMe, Root-Me.
- Hackathons tech : Devpost, MLH, défis de sécurité gouvernementaux et universitaires.
- Bonnes pratiques CV : Mettre en avant les scores CTF, certifications (eJPT, OSCP, CEH) et projets GitHub d'agents IA.
